# Android distribution metadata

The English title and descriptions describe OpenSCL4. These files are draft distribution metadata, not evidence of a store release. The current release workflow builds APKs and does not publish to F-Droid, Google Play or another store.

The numbered changelogs and screenshots under `metadata/android/en-US/` were inherited from OpenSCQ30. They describe upstream versions and interfaces, not OpenSCL4 release history or the current Compose interface. Keep them as historical material until a store submission is prepared; replace the screenshots and prepare release-specific metadata before publishing a listing.

OpenSCL4's application ID and version code come from `android/app/build.gradle.kts` and the workspace version. The old upstream changelog filenames are not version codes for the new application.

See [project origin and historical assets](../docs/history/upstream.md) and [the release guide](../docs/build-release.md).
