# Domain docs

## Before exploring

Read root GLOSSARY.md and relevant decisions in docs/adr/.
This repository uses one domain context across the Rust workspace and clients.

If either is absent, proceed silently. Domain-modeling creates documents when terms or decisions are resolved.

## Vocabulary and decisions

Use glossary terms in issue titles, proposals, hypotheses and test names.
If a needed concept is missing, reconsider the wording or note the gap for domain-modeling.

Surface conflicts with existing ADRs explicitly, citing the ADR and the reason for reopening it.
