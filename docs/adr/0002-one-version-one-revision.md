# Одна версия и исходная ревизия для общего выпуска

Стабильный выпуск Android, Windows и Linux имеет общую продуктовую версию и один Git-тег; все его пакеты собираются из одного commit общим сценарием с отдельными платформенными заданиями. Даже срочное исправление одной платформы повышает общую patch-версию и пересобирает все три платформы: дополнительная стоимость сборок принимается ради однозначного соответствия между клиентами и набором изменений. Стабильный комплект публикуется вручную только после успешных обязательных сборок и проверок. Отдельные успешные пакеты до готовности комплекта могут распространяться как предварительные.
