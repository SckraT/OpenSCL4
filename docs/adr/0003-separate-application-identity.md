# Отдельная идентичность приложения

Развиваемая линия выпускается как отдельное приложение OpenSCL4 с основным идентификатором `io.github.sckrat.openscl4`, отдельной установкой и хранилищем данных. Это позволяет независимо определять выпуск и последующие обновления, принимая чистую установку без автоматического переноса прежних настроек и пресетов; OpenSCQ30 и его данные сохраняются. Android получает отдельный постоянный release-ключ с резервной копией, первый Windows-выпуск допускается без Authenticode; внутренние имена модулей без необходимости не переименовываются.
