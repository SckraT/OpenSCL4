# Compose для Android, Slint для desktop, общее поведение в Rust

Android сохраняет Jetpack Compose; Windows, Linux и в дальнейшем macOS используют один Slint-клиент. Для обеспечения [паритета возможностей](../../GLOSSARY.md) до Linux-выпуска в общий Rust-слой переносятся повторяющиеся правила доступности настроек, шкал звуковых режимов, интерпретации заряда, валидации эквалайзера и состояния пресетов; интерфейс, транспорт и системный lifecycle остаются платформенными. Это использует работающие приложения и общие протоколы, принимая перенос ограниченного набора правил до Linux ради уменьшения расхождений между клиентами.
